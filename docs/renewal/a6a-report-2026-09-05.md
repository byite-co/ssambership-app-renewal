### 카드 블러 판단

고주파 색 띠를 카드 뒤에 둔 비교 골든에서는 블러 유무가 분명하다. 블러가
있는 쪽은 색 경계가 넓게 섞이고, 없는 쪽은 띠가 그대로 비친다. 반면 실제
사용 조건에 가까운 균질한 회청색 그라디언트의 3개 카드 목록에서는 차이가
미미하고, α0.48 채움·남색 9% 링·단일 그림자만으로 카드가 충분히 분리됐다.
따라서 콘텐츠 카드에 블러를 넣지 않는 성능 방침을 유지했다.

상단 1px 흰 하이라이트는 넣었다. 일반 배경에서도 카드 상단 곡면이 링보다
조금 밝게 드러나 깊이 구분에 도움이 되고, `BackdropFilter` 없이 정적 선 하나만
그리므로 비용이 작다.

### `design-v3.html` §0과의 차이

HTML 시안의 형태·위계는 유지하되 `design-tokens.md`를 정본으로 적용했다.

- 학생 파랑 `#1A56DB` → `#2563EB`
- 보조 글자 `#8B95A1` → `#5F6B7A`
- 주의 `#FF9500` → `#B54708`
- 위험 `#F04452` → `#C2334D`
- HTML의 내부 블록 blur 12와 saturate 효과는 사용하지 않았다. Flutter에서는
  앱바·탭바·시트만 실제 blur 15이고 카드·입력 내부는 반투명 채움과 링이다.
- HTML의 위·왼쪽 스페큘러 표현 중 카드 위 1px 하이라이트만 구현하고, 추가
  saturate 및 다중 inset 효과는 재현하지 않았다.
- 학생·멘토 배경은 동일하며 역할색은 버튼·선택 탭·배지·포커스 링에만 쓴다.

§0보다 갤러리의 유리가 덜 장식적이고 경계가 차분해 보이지만, 확정 색 대비와
스크롤 성능 방침을 더 정확히 반영한다.
