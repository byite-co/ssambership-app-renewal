## 0. 방향

**밝은 회청색 그라디언트 바탕 위에 반투명 유리 블록.** 콘텐츠도 유리다.

이전 안(회색 배경 + 불투명 카드 + 컨트롤만 유리)을 **폐기**하고 이 방향으로 확정했다. 유리가 화면 전체의 재료가 되며, 깊이는 하이라이트 링과 한 겹의 그림자로 만든다.

**판단 기준은 그대로**: 화려한가가 아니라 차분한가. 유리가 많아져도 색은 역할이 있을 때만 쓴다.

## 1. 배경

```
linear-gradient(180deg, #F6F9FD 0%, #EDF3FA 52%, #F2F6FB 100%)
```

위에서 아래로 아주 옅은 회청색. **역할색 색기는 없다** — 그라디언트 자체가 유리를 흐릴 대상이다.

```dart
BoxDecoration(gradient: LinearGradient(
  begin: Alignment.topCenter, end: Alignment.bottomCenter,
  stops: [0.0, 0.52, 1.0],
  colors: [Color(0xFFF6F9FD), Color(0xFFEDF3FA), Color(0xFFF2F6FB)],
))
```

## 2. 유리 — 두 단계

### 2-1. 유리 패널 (카드 · 시트 · 바)


배경 그라디언트 위 실효색은 약 `#F6F9FC`.

### 2-2. 유리 안쪽 채움 (패널 안의 블록 · 입력 필드)

```
채움        rgba(255,255,255, 0.58)
블러        12px
모서리      12

```

```
블러        15px
```

패널보다 진하다. 컨트롤은 뒤가 덜 비쳐야 안정적이다.

### 2-4. 시트 스크림

`rgba(28,42,74, 0.14)` 정도. 시트와 아래 화면이 붙어 보이지 않게.

## 3. 색 토큰 — 확정, 변경 금지

### 3-1. 역할색

```
학생 파랑   #2563EB     면 · 글자 (실제 앱 값 · 유리 위 4.89:1 통과)
멘토 초록   #0B6B4E     면 · 글자 (v3 값 · 유리 위 6.16:1 통과)
```

**멘토는 앱 브랜드 `#059669`가 아니다.** 유리 위에서 3.57:1로 미달이다. v3가 유리 위에서 고른 `#0B6B4E`를 쓴다.

버튼 채움은 역할색 `α0.92` — 살짝 비친다.

```
학생 버튼   rgba(37,99,235, 0.92)
멘토 버튼   rgba(11,107,78, 0.92)
```

역할 틴트(옅은 채움 · 배지 배경):
```
학생 틴트   rgba(37,99,235, 0.07~0.10)
멘토 틴트   rgba(11,107,78, 0.08~0.11)
```

### 3-2. 글자

```
본문        #191F28     15.7:1
보조        #5F6B7A      5.1:1   ← v3의 #8B95A1은 2.88로 미달, 교체
```

### 3-3. 상태

```
성공        #0B6B4E     (멘토 초록과 동일)
주의        #B54708
위험        #C2334D
```

### 3-4. 경계

```
링          rgba(28,42,74, 0.07~0.09)     유리 패널 안쪽 1px
```

이전 안과 달리 **경계선을 쓴다.** 단 단색 선이 아니라 남색 7~9% 안쪽 링이다. 유리 가장자리를 정의하는 용도이며, 콘텐츠 사이 구분선으로는 쓰지 않는다.

## 7. 구조 판단 — v3에 포함된 것

v3가 그리면서 내린 판단이다. 전부 수용한다.

- **학생 탭에 마이페이지 없음.** 앱바 우측 아이콘. 탭 하나를 쓰면 커뮤니티·알림이 밀린다
- **멘토 질문방은 답변 대기 우선 정렬 고정.** 정렬 옵션 없음 — 선택지는 결정 비용만 늘린다
- **커뮤니티 탭에 알림 배지 없음.** 학습 흐름과 목적이 달라 질문하러 온 학생이 새어 나간다

## 8. Flutter 구현 방침 ★

v3는 콘텐츠 카드까지 유리다. **목록 화면에서 카드 6장이 각각 `BackdropFilter`를 가지면 스크롤이 무거워진다.** 블러는 GPU 비용이 크고 겹치면 배가된다.

**해법 — 블러는 세 곳만, 카드는 "유리처럼 보이게".**

| 대상 | 구현 |
|---|---|
| 앱바 · 탭바 · 시트 | `ClipRect` + `BackdropFilter(blur 15)` + 반투명 채움 — 진짜 유리 |
| **콘텐츠 카드** | **`BackdropFilter` 없이** 반투명 흰 채움(α0.48) + 하이라이트 링 + 그림자만 |

배경이 균질한 그라디언트라 **카드 뒤에 흐릴 게 거의 없다.** 블러를 빼도 시각 차이가 미미하고, 골든 테스트로 그 차이를 확인한다. 차이가 눈에 띄면 그때 카드에도 블러를 넣되, `RepaintBoundary`로 감싸 재렌더를 격리한다.

```dart
// 카드 — 블러 없음
Container(
  decoration: BoxDecoration(
    color: Colors.white.withOpacity(0.48),
    borderRadius: BorderRadius.circular(16),
    boxShadow: [
      BoxShadow(color: Color(0x141C2A4A), offset: Offset(0, 8), blurRadius: 32),
    ],
  ),
  foregroundDecoration: BoxDecoration(   // 하이라이트 링
    borderRadius: BorderRadius.circular(16),
    border: Border.all(color: Color(0x171C2A4A), width: 1),
  ),
)
```

위 하이라이트(`inset 0 1px 0 white 50%`)는 Flutter에 inset shadow가 없어 **`Stack`으로 1px 흰 선을 상단에 올리거나 생략**한다. 생략해도 방향은 유지된다.

## 10. 폐기된 것

이전 문서(`20260904`)의 다음 결정은 **폐기**한다.

- 회색 배경 `#F4F5F7` + 화면 끝 역할색 색기
- 카드 불투명 흰색 · 경계선 없음 · 그림자 없음
- 유리는 컨트롤만
- 카드 간격 12px 규칙 (v3는 그림자와 링으로 분리하므로 간격 규칙이 다르다)
