## 2. 주입 구조

### `AppScope` / `AppDependencies` (`lib/app/app_scope.dart`)

- `InheritedWidget` 하나. `AppScope.of(context)` 는 `getInheritedWidgetOfExactType` 로 **등록 없이 조회**만 하므로
  `initState` 에서도 쓴다(의존성 묶음은 앱 수명 동안 불변).
- 앱 시작: `main()` 이 기존 싱글턴을 부팅한 뒤 `AppDependencies.production()` 을 만들어 `SsambershipApp` 에 넘기고,
  루트가 `AppScope` 로 감싼다(`lib/app/app.dart`). 싱글턴 클래스는 그대로 있다.
- **폴백**: 조상에 `AppScope` 가 없으면 `AppDependencies.production()`(싱글턴)으로 폴백한다. 기존 위젯 테스트 1,517건이
  AppScope 없이 화면을 직접 pump 하는데 무수정으로 종전과 같이 동작하는 근거다. A-3 에서 진입점이 전부 스코프 아래로
  들어오면 제거한다(`question_room_tab_singleton_fallback` 골든이 이 폴백 동작을 고정).
