## 3. 구독 결제 ★ — 원칙 검증

- **멱등 키**: 시트를 열 때 uuid v4(`shared/ids/uuid_v4.dart` — `Random.secure`, 외부 패키지 0) 하나. 같은 요금제 재시도에는 **같은 키**(네트워크 실패 뒤 재탭 → 서버가 첫 결과 재생, `idempotent: true` 면 `이미 완료된 결제예요` 안내). 요금제를 바꾸면 새 키. `IDEMPOTENCY_KEY_CONFLICT/INVALID` 면 새 키.
- **이중 탭 방지**: 요청 중 `_submitting` → 버튼 `결제 중…` 비활성. 테스트: 게이트로 요청을 잡아두고 재탭 → 호출 1회.
- **오류 6종 매핑**(`subscription_commerce_messages.dart`, 웹 `mapConfirmSubscriptionError` 문구 동일 · 지시서 지정 문구 우선): `CASH_INSUFFICIENT` → `잔액이 39,200원 부족해요`(`shortfall_cents`) · `MENTOR_CAP_EXCEEDED` → `정원이 찼어요` · `ALREADY_SUBSCRIBED` → 시트 닫고 구독 여부 재조회 · `MENTOR_PAUSED` → 웹 문장 · `MENTOR_TERMINATED` · `BLOCKED`. 그 외 F12 계열(`PLAN_AMOUNT_CHANGED`·`ROOM_ENSURE_FAILED`·원장 이상 계열)도 웹 사전 그대로.
- **충전 유도 0**: 사전 전 문구 `충전` 0(테스트 `문구 사전` 그룹) · 시트·카드·환불·개별질문 화면 `충전` 0 단언 · 부족 시 버튼 비활성 + 부족액 문장만.
- **가격**: `mentor_plans` 활성 행만(목록 항목의 plans, 비면 `fetchListItemById` 재조회). 요약은 서버 `mentor_plans.amount_cents` 로 계산한 표시값이며 실제 차감액은 래퍼가 DB 에서 다시 읽는다(`PLAN_AMOUNT_CHANGED` 시 차감 0).
- **성공 후**: `DataRefreshBus.bumpSubscription/bumpWallet/bumpQuestionRooms` → 멘토 상세 CTA·마이페이지 지갑·질문방 목록 재조회. `AppNavigation.finishAtLocation('/rooms/<room_id>')`.
- **본인인증 게이트**: §4.

## 4. 본인인증 게이트 — 웹 플래그 미러

- `lib/core/identity/identity_gate.dart`: `.env` 의 `IDENTITY_GATE_ENABLED` 를 웹(`lib/identity/identityGateFlag.ts`)과 **같은 이름·같은 판정**(`'true'` 만 ON)으로 읽는다. `.env.example` 에 항목 추가.
- ON 이면 `구독하기` 탭 시 `users.identity_verified_at`(authenticated SELECT — 1단계 실측)을 읽어 미인증 학생은 시트 대신 `본인인증 후 구독할 수 있어요` 시트 + `본인인증 하러 가기` → 웹 `/onboarding/verify`(`WebBridge.openIdentityVerify` — 외부 브라우저, 기존 브릿지 규약). 판독 실패는 fail-closed(웹 `requireVerifiedIdentity` 동일).
- OFF 면 판독 없이 시트. **웹 배포값과 앱 `.env` 값은 오너가 함께 맞춘다**(DB 가드 없음 — DB-4 §6-1).

## 11. 하지 않은 것 · 주의

- **요금제 변경(라이트로 낮추기, §5-8 목업)** — 래퍼 없음. 시트에는 넣지 않았다.
- **종료 확정·잔여 환불** — 관리자(웹 콘솔). 앱은 `terminating` 예약까지.
- **개별질문 과목 클라이언트 강제** — 공개형 미선택은 서버 `SUBJECT_REQUIRED` 로 거부하고 문구로 안내한다(클라이언트에서 막으면 기존 동작 테스트(공개형 제출)를 바꿔야 해서 두지 않았다).
- **`user_profile_update_self`(v1) 잔존** — 재학 상태를 안 바꾸는 저장은 v1 그대로(감소 0). 전환은 별도 결정.
- **이번에 남긴 웹 문구**(범위 밖): `login_screen` 회원가입 안내 · `my_activity_view` 빈 상태(`웹에서 글을 쓰면`) · 회원 탈퇴 웹 폴백 · 약관/개인정보/고객지원/리뷰 링크 · 숏폼 작성 WebView. 커뮤니티·계정 트랙에서 정리.
- **라이브 DB**: 1단계 카탈로그 SELECT 만(함수 시그니처·컬럼 권한·`subjects.code`). 쓰기·RPC 호출 0.
- **`IDENTITY_GATE_ENABLED` 운영값**: 앱 `.env` 는 빈 값(OFF)으로 커밋되지 않는다(`.env` 는 gitignore). 출시 빌드 시 웹 배포값과 맞출 것.
