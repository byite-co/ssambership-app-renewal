## 1. 결함 수정 9건 — 항목별 판정

### C4 — 멘토 상태칩: '진행 중'과 '답변 완료' 색 구분 (수정: info tone 을 역할 무관 파랑으로)

- [ ] 멘토 계정 → 질문 목록: **'진행 중' 칩이 파랑**, '답변 완료' 칩이 초록 — 한눈에 구분된다
- [ ] 학생 계정 → 같은 화면 계열: 종전과 동일(변화 없음)
- [ ] (부수·적대적 검증 마감분) 멘토 화면의 **알림 안읽음 개수 배지는 여전히 멘토 초록**이다
      — 개수 배지까지 파랑이 됐다면 FAIL (CountBadge 는 정체성 색 유지가 맞다)

### C8 — 개별질문: 텍스트 전송 후 하단 미정렬 (수정: 끝 점프 루프 조기 종료 제거)

- [ ] 메시지가 화면을 넘길 만큼 쌓인 개별질문 방에서 **텍스트 전송 → 자동으로 맨 아래**로 정렬된다
- [ ] 연속으로 2~3건 보내도 매번 하단 수렴한다

### C9 — 개별질문: 이미지 전송 시 맨 위로 튐 (수정: C8 과 동일 뿌리 + 목록 증가 리스너)

- [ ] **이미지가 섞인 긴 타임라인**에서 이미지 전송 → 위로 튀지 않고 하단에 수렴한다
      (이미지 높이가 잡히는 한 프레임 뒤에도 따라가야 한다 — 잠깐 튀었다 돌아오는 것은 PASS)
- [ ] 긴 타임라인 방에 **진입 직후**에도 끝(최신 메시지)으로 수렴한다

### C3 — 멘토 답변 화면: 첨부 전 주석(첨삭) 버튼 미노출 (수정: 학생과 동일 배선)

- [ ] 멘토 답변 화면에서 이미지를 첨부 **대기 슬롯에 올린 상태**에서 주석 버튼이 보인다
- [ ] 주석 작성 → 전송 → 주석이 반영된 이미지가 전송된다 (학생 화면과 동일 체감)

### B6 — 개별질문 요구 조건 미표시 (수정: 앱 모델 필드 + 칩 · 서버 RPC 2컬럼은 발효됨)

- [ ] 멘토 공개형 **대기 목록** 카드에 과목·요구 학교군·요구 계열 **칩이 표시**된다
- [ ] **과목이 한글 라벨**이다 (예: `korean_reading` 이 아니라 **독서**) — 영문 코드가 새면 FAIL
- [ ] 칩 문구가 **웹 작성 폼 어휘와 동일**하다 ('서연고 이상'·'메디컬 계열' 같은 지어낸 서열 문구가 보이면 FAIL)
- [ ] 요구 조건이 없는 공개형 질문은 칩 없이 정상 표시된다 (깨짐·빈 칩 없음)

### C6 — 열어둔 글이 삭제돼도 계속 표시 (수정: 복귀 시 존재 재확인 + 안내 화면)

- [ ] 학생 앱에서 커뮤니티 글 상세를 열어둔다 → 웹/관리자에서 그 글 삭제 → 앱을 백그라운드에 보냈다가
      **복귀 → 안내 화면으로 교체**된다
- [ ] **자동으로 닫히지 않는다** (댓글 작성 중 보호 — 갑자기 pop 되면 FAIL)
- [ ] 안내 문구가 '삭제된 글'로 **단정하지 않는다** (비공개 전환도 같은 화면 — '접근할 수 없다' 계열이 정답)
- [ ] 비행기 모드로 복귀 시 **네트워크 실패를 삭제로 오판하지 않는다**

### C7 — 차단 목록에 전원 "사용자" 표시 (수정: 정의자 RPC my_blocked_users — 서버 발효됨)

- [ ] 설정 → 차단 목록: 차단 상대의 **실제 닉네임이 표시**된다 — 전원 '사용자'면 FAIL
      (서버 RPC 는 원격 발효 확인됨 — 폴백 표시가 나오면 앱→서버 경로 문제다)
- [ ] 차단 해제가 정상 동작한다
- [ ] 차단 0명 계정에서 빈 목록이 정상 표시된다 (오류 화면 아님)

### B5 — PDF 한 장만 첨부됨 (수정: 최대 5장 선택 + 순차 자동 전송)

- [ ] 학생 채팅에서 PDF 첨부 → 페이지 선택 그리드에서 **최대 5장까지 선택**된다 (종전 1장 제한이면 FAIL)
- [ ] 전송: **첫 장은 미리보기 슬롯**(주석·본문 동봉 가능), 나머지는 **한 장씩 순차 자동 전송**된다
- [ ] 5장 모두 타임라인에 도착한다 — 조용히 일부만 가고 성공처럼 보이면 FAIL
- [ ] (가능하면) 전송 중 네트워크 차단 → **중단 + 몇 장 갔는지 알림**이 뜬다
- [ ] 멘토 답변 화면에서도 동일 규칙이다

### C5 — 게시판 필터 칩 선택 표시 고정 (수정: d72e09f — _selectCategory setState 누락)

- [ ] 커뮤니티 게시판에서 카테고리 칩을 탭 → **선택 표시(배경·테두리·굵기)가 탭한 칩으로 이동**한다
      — '전체' 칩에 고정돼 있으면 FAIL
- [ ] 목록 내용도 해당 카테고리로 필터링된다 (값 반영은 QA 시점에도 정상이었다 — 표시만 보면 된다)
- [ ] 칩을 오가며 3~4회 반복해도 표시가 항상 따라온다
